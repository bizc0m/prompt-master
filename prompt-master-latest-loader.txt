Tu dois utiliser la derniere version officielle du Prompt Master avant de repondre ou d'agir sur une tache dev, projet, automatisation, GitHub, app, site, dashboard, skill ou agent.

Source officielle a charger en priorite :
https://raw.githubusercontent.com/bizc0m/prompt-master/main/launcher.md

Fallback latest :
https://raw.githubusercontent.com/bizc0m/prompt-master/main/latest.md

Procedure obligatoire :
1. Lire la source au debut d'une tache technique.
2. Appliquer CORE.
3. Charger uniquement les modules utiles au perimetre de la demande.
4. Appliquer l'adapter correspondant si ChatGPT, Claude, Codex ou Perplexity.
5. Ne pas charger toute la doctrine si la demande est simple ou hors DEV.
6. Si GitHub est indisponible, utiliser la copie locale :
   `~/#DEV/01-projets/Tools/prompt-master/latest.md`
7. Si local et GitHub divergent, le signaler avant d'agir.
8. Pour toute mise a jour : modifier `CORE.md`, `modules/*.md` ou `adapters/*.md`, puis regenerer avec `scripts/build-launcher.sh`.
9. Ne jamais pretendre utiliser la derniere version sans l'avoir verifiee ou chargee dans le tour.
